# Sheets

Excel-like spreadsheet PWA. Colour-code cells, run simple formulas, print to PDF, and work offline.

**Buy once. Own forever.**

## Live app

After deploy: https://sheets.vercel.app (or the Vercel URL shown after publish)

## Features

- Editable grid with keyboard navigation
- Fill + text colour pickers
- Preset colours for different additions (header, income, expense, highlight, notes)
- Bold / italic
- Add and delete rows and columns
- Formulas: `=SUM(A1:A10)`, `=AVERAGE(...)`, `=COUNT(...)`, and `=A1+B2` style arithmetic
- Formula bar and status bar (sum, average, count, min, max)
- Auto-save in the browser
- CSV export
- Save as PDF via Print
- Dark mode
- Installable PWA, works offline after first visit

## Use

1. Open the live URL on your phone or computer.
2. Tap **Install** (or the browser install icon) to add it to your home screen.
3. Click a cell to select. Shift-click for a range. Type or double-click to edit.
4. Use the coloured squares to mark different kinds of entries.
5. Tap **Save PDF / Print** and choose Save as PDF.

Data stays on your device. Nothing is sent to a server.
